# 产品路线图（Roadmap）

原则：**先证明策略灵（价值）→ 补数据与体验 → 再商业化**。穿插快速 win 与必须的工程地基。
全程守合规红线：纯软件工具、不代客、不公开荐股、不打包票。

## P1 · 证明价值 + 快速体验补齐
- **A1 实盘绩效跟踪**：决策/成交 → 对照后续走势 → 胜率 / 盈亏曲线 / 最大回撤（track record）
- **微信 + 飞书群机器人 webhook 推送**：盘中/风险/周末汇总推到手机
- **移动端适配 / PWA**

## P2 · 策略验证 + 归因
- **A2 回测引擎**：历史 K 线回放策略，出历史收益/胜率
- **A4 决策质量归因**：守纪律 vs 运气

## P3 · 数据与信息面升级（部分卡外部）
- 券商 QMT 接入（替换免费兜底）🔒
- 消息面：财联社快讯/公告/龙虎榜/北向 🔒
- K线 / 资金流图表可视化

## P4 · 工程地基
- SQLite→Postgres + data 自动备份
- 测试 & CI（FIFO 盈亏 / 风控 / 回测优先）
- 可观测性：日志 / 错误聚合 / LLM 成本看板
- 密钥加密存储 + 审计日志

## P5 · 交易执行闭环（守合规）
- QMT 条件单 / 一键执行（仅自用/用户自触发，不代客）
- 预警 → 执行联动

## P6 · 商业化 / SaaS（有 track record 后）
- 计费 / 订阅 / 额度 + 管理后台
- Onboarding 向导 + 多会话管理

## 贯穿全程
- 合规审计（话术/免责）
- AI 能力：模型分层（已做）/ 多模态 / 长期记忆 / 研报解析
- 数据源健康监控 + 自动切换
